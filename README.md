# PayCore

PayCore is a UPI Payment Gateway Simulator designed to demonstrate how real-world digital payment gateways operate at a system level.

The application simulates the complete lifecycle of a UPI transaction, including merchant onboarding, payment initiation, transaction status handling, callbacks, refunds, and settlements. The goal of PayCore is to provide a clear understanding of payment processing workflows using proper object-oriented analysis and design principles.

## Project Overview

Modern payment gateways handle large volumes of transactions while ensuring reliability, scalability, and clear transaction state management. PayCore models these core concepts in a simplified and educational manner, making it suitable for academic learning and system design practice.

The system supports multiple user roles and ensures that each payment operation follows a well-defined flow, from initiation to final settlement.

## Key Features

- Merchant onboarding and authentication
- UPI payment initiation and verification
- Transaction lifecycle and status tracking
- Merchant callback notifications
- Refund processing
- Transaction settlement and reporting
- Persistent storage of all transaction-related data

## Architecture

PayCore follows the MVC (Model–View–Controller) architectural pattern to ensure separation of concerns and maintainability. The application is structured into clearly defined layers for presentation, business logic, and data persistence.

## Design Approach

The system is designed using object-oriented principles and incorporates multiple design patterns to handle creation, behavior, and communication between components. Each major feature is implemented as a complete use case, covering user interface, backend logic, and data management.

## Team Contribution

This project is developed by a team of four members. Each team member owns and implements one major use case end-to-end, ensuring equal participation and adherence to project guidelines.

## Purpose

PayCore is developed as part of an academic mini-project to demonstrate:
- Object-Oriented Analysis and Design
- UML-based system modeling
- Use of design principles and patterns
- Practical application of MVC architecture
